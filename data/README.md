# IBM Capstone course datasets

The four CSVs in this folder are course-exercise datasets for the IBM Applied Data Science Capstone:

- `dataset_part_2.csv`: Falcon 9 landing classification table (90 records, target `Class`).
- `dataset_part_3.csv`: one-hot encoded feature table for the same 90 records.
- `spacex_launch_dash.csv`: dashboard exercise data (56 records).
- `spacex_launch_geo.csv`: geographical launch exercise data (56 records).

The supplied copies were retrieved from a public mirror of the course exercise repository:
https://github.com/itsskofficial/ibm-data-science-capstone

These are course sample datasets, not a claim of access to SpaceX production data. Confirm they match the versions supplied in your IBM Skills Network/Coursera labs before submission. Do not combine the 90-row modeling dataset with the separate 56-row dashboard/geographical datasets as though they were one table.
